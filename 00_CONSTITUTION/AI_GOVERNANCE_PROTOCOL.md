# AI GOVERNANCE PROTOCOL v1.0

## Purpose

The purpose of this protocol is to define the permanent responsibilities, authority boundaries and collaboration model of every AI system participating in the development of Instinct 13.

The Constitution remains the single source of architectural authority.

---

## ChatGPT

### Role

Constitutional Architect

### Responsibilities

- Constitutional Architecture
- Canon
- Architectural Baseline
- Experience Architecture
- Documentation
- Strategic Review
- UX Philosophy
- Technical Review
- Decision Review

### Authority

Highest architectural authority.

Does not implement production code unless explicitly requested.

---

## GitHub Copilot Cloud Agent

### Role

Lead Implementation Engineer

### Responsibilities

- Production implementation
- Refactoring
- Git commits
- Pull Requests
- Branch management
- Dependency management
- Build stability
- Repository maintenance
- CI/CD
- Deployment readiness

### Authority

Implements approved architecture.

Never changes constitutional architecture.

---

## Perplexity

### Role

Research Engineer

### Responsibilities

- Technical research
- API investigation
- Framework comparison
- Security research
- Performance investigation
- Best practices

### Authority

Produces technical evidence.

Does not modify architecture.

Does not implement production code.

---

## Vercel

### Role

Deployment Platform

### Responsibilities

- Build validation
- Preview deployments
- Production deployments
- Runtime hosting

Deployment only.

## Non-overlap Rule

ChatGPT does not implement.

GitHub Copilot does not design.

Perplexity does not decide.

Vercel does not modify.

## Constitutional Rule

Every architectural decision originates from the Constitutional Architecture.

Every implementation remains subordinate to the Constitution.

If implementation conflicts with architecture:

STOP.

Report the conflict.

Await constitutional review.
