# VE-001 — Baseline Validation Notes

## Baseline reference
Architectural Baseline v1.0 remains authoritative.

## Verified documentation
- Constitutional identity: Instinct 13 does not exist to classify people; it creates frameworks that help people observe what is manifesting, understand why it may be emerging, and decide what they want to cultivate next.
- Decision Log: `Manifestation` is the approved term replacing `Archetype`.
- Website rule: the website is an implementation and must not define or modify constitutional principles.
- Current documented navigation: Home, Philosophy, Manifesto, The Circle, The Mirror, Contact.
- Current documented content map includes The Code under Frameworks, but no corresponding `the-code.md` page exists in the current `website/pages` directory.

## VE-001 implementation decision
The public entry experience uses the approved/documented concepts without expanding the navigation architecture. It does not add Manifestations, Research, Journal, Collections, or About as navigation items because those were proposed in the implementation brief but are not currently documented as approved navigation.

The sequence `Disruption → Observation → Humility → Participation → Discovery` is treated strictly as the interaction flow of VE-001, not as a constitutional layer or new architectural principle.

## Known inconsistency
The implementation brief proposes a broader navigation set than the current repository documentation. Baseline documentation wins. This inconsistency is recorded here rather than silently resolved in code.

## Validation target
The implementation tests whether the existing architecture can produce:

- observation before interpretation;
- curiosity before explanation;
- progressive revelation instead of a conventional marketing hero;
- a restrained symbolic appearance of the Instinct 13 mark;
- movement only where it advances the cognitive sequence;
- red only as a state/event signal.
